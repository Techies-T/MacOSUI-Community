# Phase 6: User Interface Revamp & Role Management Enhancements

## 概要 (Overview)
フェーズ5にてバックエンドにおける「複数ロール（Multi-Role）のアサイン機能」および「特定Skillの権限付与機能」の実装が行われます。
本フェーズ（フェーズ6）では、これらのバックエンド機能をシステム管理者が直感的に操作できるようにするための、**本格的なUI（ユーザーインターフェース）の刷新**を目標とします。

## 実装予定項目 (Planned Features)

### 1. ユーザー管理画面のUI刷新 (UsersTab.jsx)
- **現状**: ユーザーへのロール割り当てが単一選択（プルダウン）または簡易的なテキスト入力となっている。
- **改修内容**: 
  - システムに存在する全ロール（admin, user, researcher, its 等）を動的に読み込み、**複数選択可能なチェックボックスリスト**として表示する。
  - 選択されたロールを自動でカンマ区切りの文字列に変換し、バックエンドへ保存するロジックの構築。

### 2. ロール・権限管理画面のUI拡張 (RolesTab.jsx)
- **現状**: アプリ（Widget）およびアクションがハードコードされたリストで表示されている。
- **改修内容**:
  - `skills` テーブル等から登録済みの外部スキル一覧を動的に取得し、管理画面に一覧表示させる。
  - 各ロールに対して、どのスキルへのアクセスを許可するかをチェックボックスで一括管理できるUIへの完全移行。

### 3. ZTA/RBACのUX向上
- 権限を持たないアプリやスキルへアクセスした際の「Access Denied」表示のデザイン改善や、管理画面でのエラーフィードバックの明確化。
