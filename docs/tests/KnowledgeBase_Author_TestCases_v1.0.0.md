# ナレッジベース 作成者・アバター表示機能 テストケース (v1.0.0)

本ドキュメントは、ナレッジベース（Knowledge Base）の記事における作成者名およびアバター画像の表示機能に関するテストケースを定義します。

## 1. 既存データの移行と表示（正常系）

- `[✅]` **TC-KB-01**: ナレッジベースを開いた際、既存のすべての記事リスト（左ペイン）に代表ユーザー（`minoru.inui@techiespod.jp` に紐づくユーザー名とアバター画像）が表示されていること。
- `[✅]` **TC-KB-02**: 任意の既存記事をクリックして詳細ビュー（右ペイン）を開いた際、タイトル下部に `Author: [ユーザー名]` と共にアバター画像が表示されていること。

## 2. 新規記事の作成と表示（正常系）

- `[N/A]` **TC-KB-03**: 「新しい記事を作成」から適当なタイトルと内容を入力し、「保存」ボタンをクリックして記事を作成できること。
- `[N/A]` **TC-KB-04**: 作成直後、リストの先頭に追加された新規記事に、ログイン中のユーザー（自分自身）の作成者名とアバター画像が表示されていること。
- `[N/A]` **TC-KB-05**: 作成直後、右ペインの詳細ビューのタイトル下部に、ログイン中のユーザー（自分自身）の作成者名とアバター画像が表示されていること。

## 3. UI/UX の整合性（正常系・境界値）

- `[✅]` **TC-KB-06**: アバター画像の形が正円（丸型）にくり抜かれて表示され、縦横のアスペクト比が崩れて（伸びたり潰れたりして）いないこと。
- `[N/A]` **TC-KB-07**: アバター画像が設定されていない（またはURLが無効な）ユーザーが作成した記事の場合、フォールバックとして「名前の頭文字（例：『S』など）」を含む青い丸いアイコンが代替表示されること。
- `[✅]` **TC-KB-08**: 記事のタイトルが非常に長い場合でも、一覧画面でアバター画像が押し潰されたりレイアウトが崩れたりしないこと（タイトルの末尾が省略されるなど適切にレイアウトが維持されること）。
