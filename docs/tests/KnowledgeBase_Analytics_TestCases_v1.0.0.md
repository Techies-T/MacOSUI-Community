# ナレッジベース集計機能 テストケース (v1.0.0)

本ドキュメントは、ナレッジベースの集計機能（投稿数、トークン数）およびそれをMCPチャットから照会できる仕組みに関するテストケースを定義します。

## 事前準備
1. テスト用のユーザーアカウントを複数用意する。
2. ナレッジベースに複数件の記事（Authorが異なるもの、作成日時が異なるもの）を登録しておく。
3. `scripts/update_knowledge_tokens.cjs` を実行し、既存記事のトークン数が正しくセットされている状態にしておく。

## 1. データベース・マイグレーションのテスト（正常系）

- `[ ]` **TC-KBA-01**: コマンドラインから `node scripts/update_knowledge_tokens.cjs` を実行後、データベースの `knowledge_articles` テーブルにある既存のすべての記事について、`token_count` が 0 より大きい値で更新されていること。
- `[ ]` **TC-KBA-02**: UIから新規ナレッジ記事を作成して保存した直後、データベースの該当レコードの `token_count` に正しいトークン数がセットされていること。
- `[ ]` **TC-KBA-03**: 既存の記事を編集して内容を大幅に変更・保存した後、データベースの該当レコードの `token_count` が更新後の内容に基づいて再計算された値に変更されていること。

## 2. MCP連携のテスト（正常系）

- `[ ]` **TC-KBA-04**: サーバー起動時、システム設定の「MCP Servers」一覧に、ローカルのMCPサーバーエンドポイント（例: `http://localhost:8080/mcp/knowledge/sse`）が自動登録されていること。
- `[ ]` **TC-KBA-05**: MCP Chatから「ナレッジベースのAuthorごとの月別投稿数を教えてください」と質問した際、`get_author_post_counts` ツールが呼び出され、Author名と年月ごとの投稿数が正しく返答されること。
- `[ ]` **TC-KBA-06**: MCP Chatから「ナレッジベースのAuthorごとの年別投稿数を教えて」と質問した際、`period: 'yearly'` パラメータでツールが呼ばれ、年単位で集計された投稿数が回答されること。
- `[ ]` **TC-KBA-07**: MCP Chatから「ナレッジベースの記事ごとのトークン数を教えて」と質問した際、`get_knowledge_token_counts` ツールが呼び出され、各記事のトークン数が回答されること。
- `[ ]` **TC-KBA-08**: MCP Chatから「ナレッジベースのAuthor別の合計トークン数を月ごとに教えてください」と質問した際、ツールが呼び出され、Authorごと・月ごとのトークン総数が正しく集計されて回答されること。
