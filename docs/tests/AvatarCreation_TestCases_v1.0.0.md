# アバター作成機能（Avatar Creation）テスト仕様書

本ドキュメントは、System Settings内の「Users & Groups」タブに追加されたアバター作成機能の検証項目を網羅したテスト仕様書です。
Nano Banana 2 (Gemini Image Generation) を利用した2段階の画像生成と、プロフィール画像の更新が正しく行われるかを確認します。お客様への導入時の動作確認（受け入れテスト）にも利用できます。

## テスト実行ステータス凡例
- `[ ]` 未実施 (Not Started)
- `[🏃]` 実行中 (In Progress)
- `[✅]` パス (Pass)
- `[❌]` フェイル・要修正 (Fail)
- `[N/A]` 現状テスト不可・未実装 (Not Applicable)

---

## 1. UI・表示テスト

プロフィール画像のホバーアクションやモーダルの起動・終了など、フロントエンドのUI動作を検証します。

- `[✅]` **TC-AVA-01**: System Settings > Users & Groups を開き、最上部の自身のプロフィール画像にマウスカーソルを合わせた際、画像が少し拡大し半透明のオーバーレイに「変更」という文字が表示されること。
- `[✅]` **TC-AVA-02**: 「変更」オーバーレイをクリックした際、画面中央にアバター作成用モーダル（AI Avatar Creator）が正しくポップアップ表示されること。
- `[✅]` **TC-AVA-03**: モーダル右上の「✕」ボタンをクリックした際、カメラのストリームが正しく停止し、モーダルが閉じて元の画面に戻ること。

---

## 2. カメラ・撮影機能テスト

Webカメラの制御と、キャンバスを利用した画像のスクエアクロップ（1:1）機能が正常に動作するかを検証します。

- `[✅]` **TC-AVA-04**: モーダルを開いてブラウザのカメラアクセス権限を許可した際、モーダル内にフロントカメラのライブ映像が「正方形」かつ「左右反転（鏡文字状態）」で表示されること。
- `[N/A]` **TC-AVA-05**: ブラウザ設定でカメラへのアクセスをブロックした状態でモーダルを開いた際、無限ロードにならず「カメラへのアクセスに失敗しました。権限を確認してください。」というエラー画面が表示されること。
- `[✅]` **TC-AVA-06**: カメラ映像が表示されている状態で「📸 写真を撮る」ボタンをクリックした際、映像が停止し、撮影された写真がプレビューとして静止画表示されること。
- `[✅]` **TC-AVA-07**: プレビュー画面にて「撮り直す」ボタンをクリックした際、プレビューが破棄され、再びカメラのライブ映像が正常に再開されること。

---

## 3. アバター生成プロセス（正常系）

撮影した画像をもとにGemini API経由でアバター画像が生成され、ユーザープロファイルに適用されるフローを検証します。

- `[✅]` **TC-AVA-08**: プレビュー画面から「✨ アバターを生成」ボタンをクリックした際、ローディングスピナー画面（アバター生成中...）に切り替わること。
- `[✅]` **TC-AVA-09**: 約10〜30秒後、Geminiによる画像分析・生成フローが完了し、「✓ 保存完了！」というサクセス画面に切り替わること（エラーにならないこと）。
- `[✅]` **TC-AVA-10**: サクセス画面が表示されてから約1.5秒後、モーダルが自動的に閉じ、画面がリロードされてSystem Settingsのアイコンが生成されたアニメ調のアバターに置き換わっていること。
- `[✅]` **TC-AVA-11**: データベース（またはAPI経由）で該当ユーザーの `avatar_url` が生成されたBase64の画像データ（`data:image/png;base64,...`）で更新されていること。
- `[✅]` **TC-AVA-14**: 生成したアバターが保存された後、一度ログアウトして再ログイン（Google/Passkey等）した際にも、作成したアバター画像がGoogleのプロフィール画像で上書きされずに保持されていること。
- `[✅]` **TC-AVA-15**: Active Users リストなどでアバター画像が表示される際、アスペクト比が崩れず（縦横に伸びず）に丸くトリミングされて表示されること。

---

## 4. エラーハンドリングとセキュリティ（異常系）

API通信エラー時の動作や、他ユーザーへの影響範囲を検証します。

- `[N/A]` **TC-AVA-12**: ネットワーク接続を切断した状態、または意図的に環境変数を外した状態で「✨ アバターを生成」を実行した際、「アバターの生成に失敗しました」というエラーメッセージと「やり直す」ボタンが表示されること（クラッシュしないこと）。
- `[✅]` **TC-AVA-13**: ユーザーAでアバターを変更した後、別のユーザーBでログインした際、Bのプロフィール画像は変更されておらず、Aのアバターのみが更新されていること。
